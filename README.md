# 🤝 KeenKeeper

### Never Lose Touch with the People Who Matter Most

KeenKeeper is a responsive friendship management web application that helps users maintain meaningful relationships by tracking interactions, monitoring communication history, and visualizing engagement through an intuitive dashboard.

🌐 **Live Site:** https://assignment7-sigma-rose.vercel.app/

---

# 📌 About the Project

KeenKeeper is designed to help users organize and strengthen their friendships by keeping track of interactions such as calls, text messages, and video calls. The application provides a clean and user-friendly interface for monitoring communication patterns and identifying friends who may need attention.

The project demonstrates modern frontend development using **React.js**, **Vite**, **React Router**, **Tailwind CSS**, and **Recharts**, with a focus on responsive design, reusable components, and interactive data visualization.

---

# 📋 Project Overview

## 🎯 Objective

The objective of KeenKeeper is to provide an easy and organized way to manage friendships by recording communication history, tracking interaction frequency, and presenting meaningful insights through visual statistics.

## 👥 Target Audience

- Individuals who want to stay connected with friends.
- Users looking to organize their communication history.
- Anyone interested in monitoring and improving personal relationships.

# ✨ Key Features

- 👥 View all friends with communication status indicators.
- 📞 Record and manage different interaction types, including calls, text messages, and video calls.
- ⏳ Automatically categorize friendships as **On-Track**, **Almost Due**, or **Overdue**.
- 📅 Timeline view with filtering options for different interaction types.
- 📊 Interactive dashboard with charts to visualize communication patterns.
- 📱 Fully responsive design for desktop, tablet, and mobile devices.

# ⚙️ Installation Guide

## 1️⃣ Clone the Repository

```bash

```

Navigate to the project directory.

```bash

```

Install the required dependencies.

```bash

```

Start the development server.

```bash
npm run dev
```

The application will run on:

